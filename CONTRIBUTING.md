# Contributing

Contributions to the generic workflows, synthetic fixtures, and original code are welcome.

- Keep choices such as font, color, timing, levels, and layout in project configuration. Do not encode one song's design as a default.
- Add a test using generated tones, color fields, or fictional text when changing a rendering or timing script.
- Do not commit recordings, footage, lyrics, translations, logos, fonts, model captures, impulse responses, credentials, or user-specific source manifests unless you own the redistribution rights and the maintainers have explicitly accepted that asset.
- Check that new scripts use explicit inputs, document outputs and dependencies, and do not silently replace existing files.

Open an issue or pull request describing the behavior and how you verified it.
