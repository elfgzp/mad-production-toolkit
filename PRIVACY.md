# Privacy

MAD Production Toolkit is a local collection of Codex instructions and command line scripts. Its scripts read only the input paths you provide and write the outputs you choose. They do not send audio, video, lyrics, paths, or usage data to the toolkit author or a toolkit-operated server.

If you separately use Codex, a browser, GitHub, or another service while following a skill, that service has its own data handling terms. An optional online source search is separate from the local scripts.

Local project manifests can contain source attribution, rights notes, filenames, and content hashes. Keep private project files outside this public repository. Check any archive before sharing it.

Contact: use GitHub issues at <https://github.com/elfgzp/mad-production-toolkit/issues>.
